# 🌍 AI Language Translation Tool

An AI-based language translation web application built using **Python and Streamlit**.  
The application allows users to translate text from one language to another through a simple and user-friendly interface.

## 🚀 Live Demo

🔗 https://language-translationtool.streamlit.app/

## 📌 Features

- 🌐 Translate text between multiple languages
- 🇮🇳 Supports Indian languages such as Hindi, Telugu, Tamil, Kannada, Marathi, Bengali and Gujarati
- 🌎 Supports international languages such as Spanish, French, German, Italian, Arabic, Japanese, Korean and Chinese
- 📝 Simple text input interface
- 🔄 Easy language selection
- ⚡ Fast translation
- 📱 Mobile-friendly Streamlit interface
- ☁️ Deployed online using Streamlit Community Cloud

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Requests**
- **Translation API**
- **GitHub**
- **Streamlit Community Cloud**
